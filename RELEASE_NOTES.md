# Remastered CE 0.1.4 preview

By JakeTheRipper.

Adds a distinct white-helmet icon to **Launch_Remastered_CE.exe** and the installer. The white lacquer helmet retains the gold crest and purple ties from the CE icon design. The icon is embedded at 16, 24, 32, 48, 64, 128, and 256 pixels.

Existing users can leave GitHub selected and click **Install / Update Remastered CE** in the 0.1.3 installer to receive the new launcher. Download the new installer ZIP for the matching installer icon. Windows may briefly retain an old cached icon; reopen the folder if necessary.

All seven embedded icon images were verified in both executables. The launcher passed a test-bootstrap check for the Steam app/game IDs and working directory. Existing updater, signature, cancellation, uninstall, and rollback tests passed. Generated game packs and engine are unchanged from the previously tested build.

Online signed updates and offline installation remain available. Vanilla game files are not replaced.
