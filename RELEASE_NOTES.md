# Remastered CE 0.1.9 preview

By **JakeTheRipper**.

- **Hell difficulty:** New slider position after Legendary for the base Shogun 2 campaign. Uses Legendary campaign/battle rules and AI bonuses, with required Realm Divide fame set to **-1**. Its label and Legendary-style control locks are included.
- **Proximity Fading:** New graphics checkbox directly below SSAO. Controls near-camera unit fading and saves either On or Off across restarts. Updates preserve the saved choice.
- **Battle tooltips:** Colour-coded morale and fatigue labels, retaining CE wording.

Existing users can choose **Install / Update Remastered CE** in their current installer to download this release. Fresh installations: download **RemasteredCE_Installer_Preview.zip**, extract it, and run **RemasteredCE_Setup.exe**. Both installed Steam games are required; complete game files are reconstructed locally.

The existing diplomacy fixes, smoke/blood ports, DLSS launch layout and white-helmet launcher are retained. Blood and smoke rework credited to **Orendiz**. Tooltip colours adapted from the supplied **Bug fix collection**.

The local Hell mode and proximity-fading persistence were confirmed in-game. Package checks verify the three updated asset recipes and compression, native helper instructions/targets, and package signature. A fresh in-game installation of the packaged build has not been claimed.
