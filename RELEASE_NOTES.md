# Remastered CE 0.1.10 preview

By **JakeTheRipper**.

Fixes **Unsupported destination pack** from 0.1.9: the installer now supports the localisation pack containing the new tooltip colours. Uninstall supports both older four-pack installations and the new five-pack layout.

**Download the new RemasteredCE_Installer_Preview.zip and run its RemasteredCE_Setup.exe.** Existing installer applications must be replaced for this release. Clicking Update in an older application cannot upgrade that application; it now displays a clear newer-installer message before installation.

Includes the 0.1.9 Hell difficulty, coloured morale/fatigue tooltips, and the Proximity Fading checkbox with saved On/Off settings. Game content and native patches are unchanged from 0.1.9. Blood and smoke rework: **Orendiz**.

A complete production build verified all five reconstructed packs, the engine, the DLSS runtime and launch layout in a separate verification folder. Package signing and rejection by older installers were checked. This does not claim a fresh packaged in-game test.
