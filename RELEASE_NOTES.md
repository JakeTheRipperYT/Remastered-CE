# Remastered CE 0.1.17 preview

By **JakeTheRipper**.

This release includes every prior patch recipe and adds:

- Restore the original Shogun 2 unit recruitment videos (41 land, hero and ship clips) through a new eighth pack, `data/movies.pack`.
- Add the missing launch smoke to the Boshin Parrott gun (`Cannon_common_shot_lrg`).
- Fix combat sounds being rejected when the camera is close; distant-sound culling is unchanged.

**Upgrade:** download and extract this release's installer ZIP once, then run `RemasteredCE_Setup.exe`. Earlier installers cannot install 0.1.17 because it adds an eighth pack. The game launcher is unchanged.

All three changes were confirmed in local play. The patch reconstructs files from locally installed original and Complete Edition games; complete game packs and engine DLLs are not distributed.
