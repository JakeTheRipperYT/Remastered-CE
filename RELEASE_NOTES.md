# Remastered CE 0.1.8 preview

By JakeTheRipper.

Fixes invisible **Demand Break Alliance** clan lists. Runtime capture confirmed the allied-clan row existed but its parent list box was hidden. The alliance menu now explicitly shows its offer/demand list boxes. The local correction was tested successfully across multiple clans.

The release retains the confirmed local alliance-query correction. Trade embargo, the working white-helmet launcher, DLSS, and the existing graphics/content changes are retained. Temporary diagnostic logging is excluded.

Existing users: open the installer and choose **Install / Update** to download 0.1.8. For a fresh installation, download **RemasteredCE_Installer_Preview.zip**, extract it and run **RemasteredCE_Setup.exe**. Both installed Steam games are required; complete game files are reconstructed from local installations.

Blood and smoke rework credited to **Orendiz**.

Targeted package checks verify the modified UI recipe, signature, and engine helper against the confirmed local fix. The installer application code is unchanged apart from the version label. A fresh in-game test of the packaged installer has not been claimed.
