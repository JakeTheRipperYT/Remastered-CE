# Alternate engine integration

Development sources and guarded recipes for the optional Sim Turns engine, both-engine agent/farm fixes, and alternate-only religion switching. These scripts require local game files and the established development layout; no engine compiler or complete game DLL is included. The cumulative signed release package carries the reconstruction recipes actually used by the installer. See the accompanying technical notes. For an exact setup/launcher rebuild use ../installer/Build.ps1 and the matching public .rce package.
