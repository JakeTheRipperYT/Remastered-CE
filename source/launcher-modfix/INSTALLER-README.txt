Remastered CE 0.1.25 Preview — integrated launcher mod fix 2
By JakeTheRipper

INSTALL / UPDATE
Extract this ZIP. Keep RemasteredCE_Setup.exe and its .config together.
Close the game and other launcher windows. Run RemasteredCE_Setup.exe, select
your Complete Edition and original Shogun 2 installations, and choose Install / Update.
Use Play Remastered CE with Steam running. The combined UI displays
"0.1.25 mod fix 2". Existing installations must run Install / Update once with
this new setup executable to receive the corrected installed launcher.

The installer reconstructs the patch from your locally installed games.
The original game installation stays untouched. Existing update backups and
ownership-aware uninstall remain supported. No complete game packs or engine
DLLs are distributed. The night-reinforcement changes in 0.1.25 are retained.

LAUNCHER FIXES
- Reads CE compressed sequential PFH3 packs without converting them to OG S2.
- Discovers custom mods in RemasteredCE/data while excluding base game packs.
- "Use existing user.script.txt (ignore selections)" preserves a manual mod
  script. Leave it unchecked to use the selected launcher profile instead.
- Normal installation and offline repair with this updated installer retain
  the corrected combined launcher; a separate hotfix step is not required.

Use this updated installer for offline repair of the 0.1.25 .rce package.
Older setup executables still install their original launcher. The signed
0.1.25 engine/data package is unchanged. This launcher update does not promise
compatibility with every campaign/database mod or removal of antivirus warnings.
