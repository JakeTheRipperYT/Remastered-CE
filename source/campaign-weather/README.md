# Campaign visuals and dynamic battle weather

This is the final controller used by 0.1.55, incorporating the user-confirmed0.1.54 penalty-bar correction and0.1.52 puddle material correction. It includes the night checkbox controller, persistent Always Night override, battle night-scene policy, forecast cycles, synchronized weather/environment interpolation, storm scheduling, starting terrain/puddle locks, native shader registration and unit-card stats.

The C++ source builds without imports or absolute relocations. Code and writable state are separated. Weather applies to campaign battles; custom/historical behavior remains native. Weather card values use native accuracy/reload rules and preserve other bonuses. Fatigue is excluded. Actual bar state, geometry and visibility invalidate the last-draw cache; the native negative-bar branch is explicitly re-shown after a reset.

## Rebuild the native helper

Use Windows x64, Python with requirements.txt, and MSVC x64 tools14.51.36231. The baseline .rce is the public 0.1.28 release asset, pinned by SHA-256. CE input files remain read-only. Choose a separate work directory on your work drive.

```powershell
python build_native.py --ce-root 'D:/SteamLibrary/steamapps/common/Shogun 2 Complete Edition' --baseline-package 'F:/Codex/Inputs/RemasteredCE-0.1.28-preview.rce' --work-directory 'F:/Codex/Builds/RemasteredCE55-native'
```

Outputs are helper/patch reconstruction instructions and intermediate files, not a signed release. No private signing key or complete game DLL/pack is included. The builder replays the accepted timestamp in MSVC’s type13 linker debug record; executable code and all other payload bytes are rebuilt and compared. Compiler updates can change generated bytes; native-build-inputs.json records the published helper and engine hashes. Use the signed installer for installation. PePatchCandidate.cs provides the injector implementation used in verification; source/settlement-damage covers the retained season selection repair. The signed release carries the exact cumulative asset reconstruction recipes.

Weather-transition shader helpers are in weather_transition.hlsl. The fifteen retained grass dithering assets remain byte-identical to0.1.28. Full verification results and the limits of offline/live checks are recorded in docs/release-verification-0.1.55.json.
